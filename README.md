# Tic Tac Toe Game 🎮

A simple console-based Tic Tac Toe game developed using **Java**.

## Features

* Two-player game
* Player X and Player O
* 3 × 3 game board
* Winner detection
* Draw detection
* Invalid move validation
* Console-based gameplay

## Technologies Used

* Java
* IntelliJ IDEA
* Git
* GitHub

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Open `TicTacToe.java`.
4. Run the `main()` method.
5. Enter a position from 1 to 9 to make a move.

## Game Board

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

Players take turns entering a number from **1 to 9**.
